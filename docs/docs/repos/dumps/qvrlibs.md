# qvrlibs

[gitlab.com/neosalsa/qvrlibs](https://gitlab.com/neosalsa/qvrlibs)

## What this is

QVR's supporting vendor libraries: libqti-perfd-client_system and the Tobii eye-core stubs (libtobii_eyecore_stub, libtobii_runtime), 32 and 64 bit.

## How to remake this dump

Pulled from /system/lib(64) or the vendor paths on a stock device / image.
