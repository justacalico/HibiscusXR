# issues

Issue tracking for the Neosalsa project - the LineageOS 17.1 port for the
Pico Neo 2 VR headset. Bug reports, feature requests, help questions, and
anything else you want to flag.

## How to open an issue

Go to **Issues -> New issue** on the left sidebar, or click
[here](https://gitlab.com/neosalsa/issues/-/issues/new).

Pick the template that fits:

- **Bug report** - something broken on the headset, the build, or the site
- **Feature request** - something you want the port or the software to do
- **Help** - you're stuck flashing, building, or running something

Fill in what you can. Screenshots and logs help a lot.

## Scope

This repo covers the whole neosalsa group:

- The Android port itself (device tree, overlay, shims, build scripts)
- vrhome and the library app
- The website
- The dist build pipeline
- Documentation

If it's part of Neosalsa, it belongs here.
